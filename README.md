# Система управления пользователями (Репозиторий `users`)

Простое и надежное веб-приложение на PHP для администрирования учетных записей пользователей с ролевой моделью доступа (RBAC), логированием действий и автоматической миграцией базы данных PostgreSQL.

## Особенности системы

*   **Ролевая модель (RBAC):** Поддержка ролей `owner` (Владелец), `admin` (Администратор) и `operator` (Оператор) с разграничением прав на просмотр, добавление, редактирование и удаление.
*   **Безопасность:** Хеширование паролей с помощью встроенных механизмов PHP (`password_hash`). Реализован механизм принудительной смены пароля при первом входе.
*   **Журналирование:** Полный аудит действий администраторов (вход, выход, создание, изменение и удаление учетных записей).
*   **Автомиграция:** Автоматическое развертывание структуры БД и создание первичной учетной записи владельца при первом запуске приложения.

## Стек технологий

*   **Язык программирования:** PHP 8.1+ (требуется расширение `pdo_pgsql`)
*   **База данных:** PostgreSQL
*   **Веб-сервер:** Nginx + PHP-FPM
*   **Скрипты автоматизации:** Bash

## Структура проекта

*   `index.php` — Единая точка входа, роутинг запросов.
*   `config.php` — Параметры подключения к PostgreSQL и логика автоматической миграции таблиц.
*   `auth.php` — Логика аутентификации, сессий, авторизации и смены паролей.
*   `users.php` — Панель управления пользователями (CRUD-интерфейс).
*   `logs.php` — Интерфейс просмотра журнала действий (доступен только для `owner`).
*   `functions.php` — Общие вспомогательные функции (логирование, проверка иерархии ролей).
*   `setup_db.sh` — Bash-скрипт для автоматической проверки доступности СУБД, создания базы данных и таблиц из консоли.

## Инструкция по развертыванию

### 1. Подготовка базы данных

Вы можете использовать встроенный Bash-скрипт `setup_db.sh` для первоначальной проверки и настройки PostgreSQL:

```bash
chmod +x setup_db.sh
./setup_db.sh
```

*Скрипт проверит наличие утилиты `psql`, протестирует сетевую связность, при необходимости создаст базу данных `user_db` и структуру таблицы `users`.*

### 2. Настройка конфигурации PHP

Убедитесь, что параметры подключения в файле `config.php` соответствуют вашему окружению:

```php
\(host = 'localhost';\)db   = 'user_db';
\(user = 'postgres';\)pass = 'postgres';
```

### 3. Конфигурация веб-сервера Nginx

Пример конфигурационного файла виртуального хоста для Nginx (`/etc/nginx/sites-available/pam_digest`):

```nginx
server {
    listen 8001;
    server_name 213.189.221.124;

    root /var/www/pam_digest;
    index index.php;

    access_log /var/log/nginx/pam_digest.access.log;
    error_log /var/log/nginx/pam_digest.error.log;

    charset utf-8;

    location / {
        try_files \$uri uri/ /index.php?query_string;
    }

    location ~ \.php\$ {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME \(document_root\)fastcgi_script_name;
        fastcgi_param DOCUMENT_ROOT \$document_root;
        fastcgi_pass unix:/run/php/php8.1-fpm.sock;
        fastcgi_index index.php;
    }

    location ~ /\.ht {
        deny all;
    }
}
```

Не забудьте перезапустить Nginx после применения настроек:
```bash
sudo systemctl restart nginx
```

## Первичные учетные данные

При первом запуске скрипта миграции в базе данных автоматически создается суперпользователь:

*   **Логин (ID):** `owner`
*   **Пароль:** `owner123`

> ⚠️ **Важно:** Сразу после первого входа под учетной записью `owner` настоятельно рекомендуется сменить стандартный пароль в панели управления во избежание несанкционированного доступа.
